# 📚 StudyPace

**StudyPace** is a lightweight desktop application built with Python and Tkinter designed to help students organize their exam revisions efficiently. 

## 🚀 The Problem
Students often struggle with stress and poor time management when multiple exams approach. It’s hard to prioritize which subject needs immediate attention based on deadlines and difficulty levels.

## 💡 The Solution
StudyPace allows students to:
- Add subjects with custom difficulty levels (1 to 5) and exam dates.
- Automatically track the remaining days until each exam.
- Instantly view a dynamically sorted study plan that prioritizes urgent and difficult subjects.

## 🛠️ Tech Stack
- **Language:** Python 3
- **GUI:** Tkinter & ttk
- **Storage:** Local JSON file (`schedule_data.json`)
